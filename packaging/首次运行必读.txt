========================================================================
  Publish Helper v2.0.0  首次运行必读
========================================================================

一、怎么启动
------------------------------------------------------------------------
直接双击 "Publish Helper.exe"（macOS 为 Publish Helper.app，
Linux 为 ./Publish\ Helper）。

首次启动会在**可执行文件所在目录**自动创建以下内容：

    static/     配置与数据文件（含 settings.json）
    media/      放你的视频资源
    temp/       截图与种子临时目录
    logs/       运行日志

所以请把可执行文件放在一个**有写入权限、且不会被系统清理**的目录里，
例如 D:\PublishHelper\ 。不要放在 C:\Program Files\ 或桌面临时目录，
也不要放在只读盘/网络盘上。

如果启动后没有任何反应，去看 logs/app.log。


二、⚠️ 升级前必看：PT-Gen 接口已变更（会影响老用户）
------------------------------------------------------------------------
v2.0.0 更换了 PT-Gen 接口，默认地址由

    旧：https://api.iyuu.cn/App.Movie.Ptgen

改为

    新：https://pt-gen.hares.dpdns.org/api/getData

**如果你是从 v1.5.x 升级上来的**，并且沿用旧的 static/settings.json，
那么 "获取 PT-Gen 简介" 会直接失败（旧地址已不可用）。

处理办法（二选一）：

  1. 打开软件 → 设置页 → 把 "PT-Gen 接口地址" 改成上面那个新地址；
  2. 或者删除 static/settings.json，让软件重新生成默认配置，
     然后重新填一遍你自己的设置。

注意：本版本会**保留**已存在的 settings.json（不会覆盖），
所以升级不会自动帮你换掉旧地址——这一步需要你手动做。


三、⚠️ auto_feed_link 必须替换成你自己站点的地址
------------------------------------------------------------------------
settings.json 里的 auto_feed_link 默认值是：

    https://example.com/upload.php#separator#name#linkstr#{主标题}...

其中 https://example.com/upload.php 是**占位符**，不是真实站点。
你必须把它替换成你自己 PT 站的 auto_feed 地址，否则
"一键上传" 生成的链接点开是无效的。

如何修改：打开软件 → 设置页 → 找到 auto_feed_link 一栏，整体替换为
你站点提供的链接模板（#separator# 之后的部分按你站点要求保留）。

提示：文件里写成 \u4e3b\u6807\u9898 这种是 JSON 的 Unicode 转义，
读出来就是 {主标题}，属于正常现象，不必手动改成中文。


四、图床（可选）
------------------------------------------------------------------------
默认使用 freeimage，无需配置即可用。

薄荷图床 / 兰空图床 / Chevereto 需要在设置页填 API 地址与 Token。


五、MediaInfo（Linux 用户）
------------------------------------------------------------------------
Windows 与 macOS 版本已内置/自带 libmediainfo。
Linux 用户需要自行安装：

    sudo apt-get install -y libmediainfo0v5 libzen0v5


六、卸载
------------------------------------------------------------------------
本软件不写注册表、不装服务。直接删除可执行文件所在目录即可，
你的设置与 media 也随目录一并删除。
